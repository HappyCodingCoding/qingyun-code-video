# production-spec.md 模板

用户选定方案后，把确认的内容全部填进来。production-spec.md 是这支视频的完整制作规格，第 6、7 步按它制作。

填写要求：
- 把已经确认的内容替换对应的占位符，不留「……」和「…」占位符；用户没有明确指定、采用了默认值的参数，在后面注明「默认值」。

```markdown
<overview>
- 主题：……
- 核心信息：……（看完要让观众记住的一句话）
- 原材料：……（文件路径或链接；参考视频只学结构和手法）
- 规格：…秒，画幅 …（…×… 像素，按 SKILL.md 第 4 步的画幅对照取），…fps，开场淡入 …秒（不淡入时写「无」）
- 配色：主色 …，辅色1 …, 辅色2 … （确保色彩优雅。仅在有需要时，根据这三种颜色的深浅度衍生出更多的子颜色）
- 内容字体：……（字体名称；字体文件放在项目里时，写明文件路径）
- 声音：配乐 ……（代码合成及 BPM，或用户音频文件的路径），音效 ……（用到哪几种，比如 click、whoosh；没有时写「无」），配音 ……（语音合成引擎、音色、语速，或用户配音文件的路径；不要配音时写「无」）
- 字幕：……（不显示，或颜色、字体、字号）
</overview>

<direction>
- 画风：……（渲染方式和质感，比如扁平插画、像素风、彩铅手绘、低多边形 3D；颗粒、扫描线、纸纹等质感层写在这里；按段落切换画风时，逐段写明）
- 版式：……（画面分区和对齐方式、四周留白，标题、页码等固定元素的位置）
- 文字排版：……（标题、正文各多少 px 和字重，强调用什么方式，比如变色、加粗、下划线；内容字体写在 <overview>）
- 色彩角色：……（把 <overview> 配色里的每个色值分给一个角色：背景、正文、重点色、辅助色，辅助色用于线条、图标、次要文字；写明重点色只用在哪些元素上，比如被讲解的短语、被选中的目标）
- 角色和视觉符号：……（贯穿全片的角色、物体或图形，写明外观要点和代表的含义；没有时写「无」）
- 动效语言：……（各类元素用 craft-rules.md 弹簧四档里的哪一档；动作和节拍怎么对应；转场做法；这支片子特有的标志性动作）
- 整体运镜：……（比如一镜到底、平稳跟随主角横移、每到重拍快速推近；各镜头的具体运镜写在 <structure>）
- 禁止：……（按这支片子的实际情况列出各项具体的禁止行为，包括 craft-rules.md「默认风格要主动避开」里和这支片子相关的几项）
</direction>

<structure>
时间轴：……（有配音时写「按 audio/voice.json 的逐句时间戳，下面的镜头时间是估算值」；没有配音时写节拍网格：用户提供的音乐写「按 source/beats.json」，代码合成的配乐写 BPM 和每小节秒数）

### 镜头 1｜0.0–3.0s
- 画面：……（有哪些元素、各放在哪里）
- 文字：……（画面上出现的文字，逐字写出；没有时写「无」）
- 旁白：……（这个镜头对应的旁白原文；没有配音时省略这一项）
- 动作：进场 …，主要动作 …，出场 …
- 运镜：……
- 声音：……（音效及对应的动作；配乐的变化）
- 转场：……（怎么转到下一个镜头、用时几秒，验收时按这个用时检查残留元素；最后一个镜头写结尾怎么收）

### 镜头 2｜……
……
</structure>

<build>
1. 技术组合：……（照抄选定方案的「技术组合」）
2. 运动模糊：……（照选定方案的「规格」：不加；加时写明做法，比如网页每帧 4 个子帧、Remotion 用 `<CameraMotionBlur>` 及其 `samples` 数）
</build>
```
